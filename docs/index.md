# Welcome

This guide is for anyone who wants to get hands-on with system monitoring, logging, and observability tools. It’s built like a course — starting with the basics and moving toward more advanced setups using tools like Prometheus, the ELK stack, and Splunk.

Whether you’re just getting started or already have some experience, you’ll find practical examples, labs, and explanations to help you understand how modern monitoring works.

## What’s Inside

- **Linux logging fundamentals** – journald, rsyslog, logrotate
- **Metrics & dashboards** – using Prometheus, Grafana, and TICK
- **Log aggregation** – working with Elasticsearch and Kibana
- **Security, performance tuning, and backup**
- **Final project** – put it all together with a working monitoring setup

## Who It's For

This is mainly for students learning DevOps or system administration, but anyone curious about monitoring systems is welcome. The goal is to get you comfortable with the tools and concepts that real systems use.

## How to Use This Guide

- Start with the **Fundamentals** section
- Do the **Labs** in order — they build on each other
- Use the **Final Project** to tie everything together
- If you're stuck, check the **Help** section under Final Project

---

Feel free to modify the flow or skip around if you're more experienced. Enjoy exploring.
