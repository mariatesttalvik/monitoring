    🔧 Network Troubleshooting Guide¶

    Quick Fixes¶

    1. Can't Access From Host¶

    # 1. Check if service is running
docker ps

# 2. Check actual port binding
docker port [container_name]

# 3. Test locally in VM/WSL
curl localhost:5000

# 4. Check Docker network
docker network ls
docker network inspect [network_name]

    2. Common Solutions¶

    # In docker-compose.yml
services:
  web:
    ports:
      - "0.0.0.0:5000:5000"  # Add 0.0.0.0!
    networks:
      - monitoring

networks:
  monitoring:
    driver: bridge

    3. Test Commands¶

    # Test if port is open
nc -zv localhost 5000

# Check what's using ports
sudo lsof -i :5000

# See all listening ports
sudo ss -tulpn

    Easy Commands to Remember¶

    In VM/WSL:¶

    # Get your IP
ip addr show

# Test web server
curl localhost:5000

# Check Docker containers
docker ps

    On Windows Host:¶

    # Test connection
Test-NetConnection -ComputerName localhost -Port 5000

# Find VM/WSL IP
ipconfig

    Common Problems¶

    1. "Connection refused"
    2. Check if service is running
    3. Verify port forwarding

    4. Check firewall

    5. "Can't connect to docker daemon"

    6. Start docker service: 

      sudo service docker start

    7. "Port already in use"

    8. Find and stop process: 
      sudo lsof -i :5000
sudo kill [PID]
